# SachiArambh frontend

React + Vite with JavaScript and Tailwind CSS. See the [project setup guide](../README.md)
for environment configuration, backend communication, and run commands.

The development server forwards `/api` requests to the local FastAPI backend.
Four main routes are implemented: Home, About, Privacy, and Safety.
Mode cards open static educational previews, not live AI assessments.
Photography and fonts are self-hosted; credits appear on the Privacy page.
